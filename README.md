# Django Advanced

Welcome to my repository for the **Django Advanced** course, part of the **Software Engineer with Python** learning path at **SoftUni** (Software University).

This repository contains all my code, lecture examples, lab exercises, workshops, and notes created during the course.

---

## 📚 Course Overview

The **Django Advanced** course dives deep into complex web application architecture, security, performance optimization, and scalable backend services using the Django framework and Python ecosystem.

### Key Learning Objectives:
* Advanced User Authentication and Authorization strategies.
* Customizing and extending the Django User Model.
* Event-driven programming with Django Signals.
* Custom Middlewares, Session Management, and Web Security.
* Building RESTful APIs using Django REST Framework (DRF).
* Asynchronous background tasks with Celery & Redis.
* Comprehensive Unit and Integration Testing for Django applications.
* Production Deployment setup with Gunicorn and Nginx.

---

## 📑 Curriculum & Topics

Below is the detailed list of topics covered throughout the course:

### 1. Django Authentication and Authorization
* What is Authentication vs. Authorization?
* Authentication flow in Django
* User Model and Password Management
* Permissions and Authorization in Django
* Managing Groups and Roles

### 2. Extending User Model & Django Signals
* Overview of extending the User Model
* Using Proxy Models
* Using One-to-One Relationships (Profile models)
* Extending `AbstractUser` vs. `AbstractBaseUser`
* Event-driven architecture with Django Signals

### 3. Django Middlewares & Sessions
* Understanding Middlewares in Django
* Built-in Django Middleware Classes
* Creating Custom Middleware
* Working with Django Sessions and Session Data
* Understanding Cookies, Sessions, and Web Security

### 4. Deployment Setup
* Production setup concepts
* WSGI Application Server with **Gunicorn**
* Reverse Proxy and Web Server with **Nginx**
* Initial server configuration and deployment steps

### 5. Django REST Framework (DRF) Basics
* Understanding RESTful APIs and HTTP verbs
* Introduction to Django REST Framework
* DRF Installation and Requirements
* Building API Views using DRF's `APIView`
* Working with Serializers in DRF

### 6. Django REST Framework (DRF) Advanced
* Advanced Serialization techniques (Nested Serializers, Custom Fields)
* Using Generic Views and ViewSets in DRF
* Authentication and Permissions in DRF (Token / JWT / Session)
* Exception Handling and custom API responses

### 7. Asynchronous Processing with Celery & Redis
* Introduction to Asynchronous Tasks in Web Development
* Overview of **Celery**
* Using **Redis** / **RabbitMQ** as Message Brokers for Celery
* Configuring Celery with Django projects
* Creating, invoking, and managing background tasks
* Error handling and debugging with Celery

### 8. Testing in Django Projects
* Unit and Integration Testing concepts
* Testing Best Practices and Structure
* Testing Django Models, Views, Forms, and API Endpoints
